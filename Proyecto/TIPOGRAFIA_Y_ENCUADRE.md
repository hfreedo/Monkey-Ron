# Luckiest Guy — Monkey Ron v5

Luckiest Guy aplicada a títulos y botones, con márgenes interiores y ajuste de tamaño. Las instrucciones y contadores conservan Segoe UI. El título ilustrado del juego sigue siendo una imagen.

La fuente está registrada para el usuario actual de Windows. Si Construct 2 estaba abierto, cerrarlo y volver a abrirlo para actualizar la lista de fuentes.

El CAPX incorpora LuckiestGuy-Regular.ttf, su licencia y luckiest-guy.css. Al iniciar cada layout, sus textos decorativos solicitan la CSS local mediante Set web font. La CSS incluye la fuente en sus propios datos, sin descarga desde Google. En otro equipo, instalar el TTF incluido para verlo también en el editor.

Origen: https://github.com/google/fonts/tree/main/apache/luckiestguy . Se incluye LICENSE.txt de la distribución original. Se comprobaron tildes, ñ y signos españoles.

Verificación: 22 comprobaciones de modelo y estructura; 12 composiciones HTML sin desbordamiento. La vista HTML usa la fuente local.
